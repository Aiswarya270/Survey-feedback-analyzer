# Survey-feedback-analyzer
A simple Python project to analyze and summarize survey feedback
This is a Python project created as part of my Python Fundamentals assignment.

The project analyzes customer survey feedback and gives some basic insights from the data.
**What this project does:**
- Stores feedback data using a dictionary of lists
- Allows the user to add new feedbacks
- Cleans the feedback text
- Counts feedbacks containing words like good, poor, and excellent
- Calculates the average rating
- Finds the feedback with the longest comment
- Finds unique words used in the feedbacks
**Python Concepts Used***
- Dictionary
- Lists
- Loops
- if conditions
- Functions
- String methods
- split() and join()
- replace()
- lower()
- set()
- Basic calculations
**How to Run**
1. Download or clone this repository.
2. Open the Python file.
3. Run the program.
4. Enter the required feedback details when asked.
